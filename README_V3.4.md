# ELC SPEC V3.4 — 資料品質檢核／CAD 補寫

由已部署的 V3.3 原始程式修改。沿用所有既有 Vercel 環境變數與 Notion 資料庫，不必重新建立資料庫。

## 本版實作
- 新匯入燈具即產生動態編號 CAD 規格文字並寫入專案燈具庫。
- 新增 `/api/cad`：先唯讀檢核 CAD 空白／產品關聯／專案關聯，按專案執行「只補寫空白 CAD 文字」。
- 不覆蓋已存在的 CAD 文字、不更新既有產品資料、不更動舊專案的規格數據。
- CAD 預覽最後保留原始預算文字，避免解析器遺漏特殊規格；若原始資料未驗證，不應將其視作原廠確認。

## 尚未涵蓋
- DXF 實際 AutoCAD 驗證。
- 與原始 Excel 逐項比對（需要原始台光電預算檔或該次匯入 manifest）。
- 依 Notion 欄位變更自動觸發更新（目前需手動按檢核／補寫）。
- LINE Messaging API。

## 部署
解壓縮後將專案內容更新到原 Vercel 專案；不要上傳 .env 或實際 Token；部署完成後先按「讀取 Notion 最新資料」，再使用 CAD 檢核，確認預覽正確後才填補空白欄位。
